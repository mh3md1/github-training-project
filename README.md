## How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/mh3md1/github-training-project.git
```

2. Open the project

```bash
cd github-training-project
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
